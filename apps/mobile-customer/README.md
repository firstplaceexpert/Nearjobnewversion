# NEAR JOB — Mobile Customer App (React Native / Expo)

Aplikasi mobile untuk **Pelanggan / Pemberi Tugas (Customer)** berbasis React Native & Expo, terintegrasi langsung dengan **Laravel Backend API**.

## Fitur Utama:

- **Layanan Gojek-Style**: NearRide (Ojek Motor), NearSend (Kurir Kilat), NearFood, NearClean, & Jasa Kustom.
- **Pemesanan Instan**: Form order dengan estimasi tarif otomatis & integrasi ke backend API `/api/tasks`.
- **Live Status Tracking**: Memantau progres mitra secara realtime (`Mencari Driver` → `Driver OTW` → `Driver Tiba` → `Sedang Dikerjakan` → `Selesai`).
- **NearPay Wallet**: Saldo digital terintegrasi dengan top-up instan.

## Cara Menjalankan:

```bash
cd apps/mobile-customer
npm install
npx expo start
```

- Tekan `i` untuk membuka iOS Simulator
- Tekan `a` untuk membuka Android Emulator
- Atau scan QR Code di aplikasi **Expo Go** pada smartphone fisik Anda.
