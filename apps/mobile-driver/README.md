# NEAR JOB — Mobile Driver / Mitra Partner App (React Native / Expo)

Aplikasi mobile untuk **Penyedia Jasa / Pengemudi / Mitra Pelaksana (Driver / GoPartner)** berbasis React Native & Expo, terintegrasi langsung dengan **Laravel Backend API**.

## Fitur Utama:

- **Switch Status Siap Kerja (Online / Offline)**: Mengaktifkan radar pencarian order dalam radius 5 km.
- **Radar Orderan Masuk**: Peringatan audio-visual dengan **countdown timer 20 detik**, rincian alamat, jarak tempuh, dan pendapatan bersih mitra (sudah dipotong komisi platform).
- **Progres Bertahap (Step Tracker)**:
  1. `🚗 Mulai Meluncur (OTW)`
  2. `📍 Sudah Sampai di Lokasi`
  3. `🛠️ Mulai Pengerjaan`
  4. `✅ Selesaikan Pekerjaan`
- **Dompet & Tarik Saldo Instan**: Pencairan ke BCA, Mandiri, BRI, GoPay, dan OVO.
- **Profil & Performa**: Rating bintang 4.98 ⭐, 98% Acceptance Rate, 100% Completion Rate, dan data kendaraan kerja.

## Cara Menjalankan:

```bash
cd apps/mobile-driver
npm install
npx expo start
```

- Tekan `i` untuk membuka iOS Simulator
- Tekan `a` untuk membuka Android Emulator
- Atau scan QR Code di aplikasi **Expo Go** pada smartphone fisik Anda.
